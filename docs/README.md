# XAN Documentation

Project documentation is collected here so the repository root stays focused on the Android/Gradle project.

## Project guides

- [Contributing](CONTRIBUTING.md) — project layout, local builds, branches and pull requests.
- [Security](SECURITY.md) — supported versions and private vulnerability reporting.
- [Modules](MODULES.md) — music-source, lyrics, service, visual and experimental modules.
- [Tools](TOOLS.md) — maintenance scripts and Windows helpers.
- [Windows tools](WINDOWS-TOOLS.md) — build, update and dependency helper usage.

## Repository areas

- `../app/` — Android application.
- `../modules/` — grouped Gradle modules.
- `../tools/` — developer/build/update utilities.
- `../gradle/` — Gradle wrapper and version catalog.
- `../.github/` — GitHub Actions, issue templates and repository automation.

Files required by Gradle or external services remain at the repository root instead of being moved solely for appearance.
